# Лабораторная работа №2 — вариант 3

## Приложение «Траектория движения»

Используемые порождающие паттерны: **Абстрактная фабрика** и **Прототип**.

### Быстрый запуск

1. Установите .NET 8 SDK.
2. Откройте `TrajectoryMovementLab.sln` в Visual Studio.
3. Запустите проект через `Ctrl+F5`.

Либо откройте терминал в корне архива и выполните:

`dotnet run --project TrajectoryMovementLab/TrajectoryMovementLab.csproj`

Готовый отчёт находится в папке `Report`. UML-диаграммы — в папке `UML`.
