# Лабораторная работа №2 — вариант 3

## «Траектория движения»

Консольное приложение на C# / .NET 8. В работе демонстрируются два порождающих паттерна:

- **Абстрактная фабрика** — создаёт семейство объектов для двух моделей движения: идеальной и с постоянной попутной/встречной скоростью ветра.
- **Прототип** — хранит базовый сценарий и создаёт независимые копии через `Clone()`; затем клоны изменяются без изменения исходного сценария.

### Запуск

1. Установить .NET 8 SDK.
2. Открыть `TrajectoryMovementLab.csproj` в Visual Studio или открыть папку в VS Code.
3. Выполнить `dotnet run`.

### Структура

`Models` — предметные объекты, `Motion` — расчётные продукты, `Factories` — Abstract Factory, `Presentation` — форматтеры результатов, `Patterns` — интерфейс и реестр Prototype.
